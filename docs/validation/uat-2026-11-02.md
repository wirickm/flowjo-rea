# Front-end acceptance test and fix decisions (2026-11-02)

This record explains **why** each fix from the 2026-11-02 acceptance test was
made the way it was. For each defect it names what FlowJo 10.6.2 does (from
static reading, specs section 6), the decision, the reason, and the test that
holds it in place.

## 1. Test (FJR-UAT-01)

- Method: five operators used the app through a real Chromium browser. They
  read labels and screenshots and clicked, dragged and typed like a user; no
  internal APIs were called.
- Datasets: D1 8-color ICS FCS (3 files); D2 FlowJo 10 `.wsp` workspaces; D3
  ISAC Gating-ML 2.0 set; D4 matrix CSVs, single-stain controls, spectral
  CSVs; D5 noncompliant, multi-data-set and older FCS; synthetic cell cycle
  and proliferation data.
- Result: 234 controls tested, 153 pass, 24 fail, 56 observations, 1 not
  reached; no crashes and no uncaught page errors.
- Severity: S1 crash or data loss, S2 feature broken, S3 minor or wrong
  output, S4 cosmetic.

## 2. FlowJo investigation (REA method)

Each defect became a question in `rea-investigation-checklist.md` (Q12 to
Q18). Evidence came from the verified FlowJo 10.6.2 installer (SHA-256
`90721621...`, same as `tools/rea-originals.json`): `javap` of the Java
classes (names, signatures, constants) and the native engine's symbols.
Behaviors are written in our own words in specs section 6. No FlowJo code,
bytecode listing or disassembly is in the repository. FlowJo was not run
(macOS only), so runtime behavior stays unconfirmed (checklist Q10).

Decision rule:
- **Match FlowJo** when FlowJo has a clear behavior. This app targets FlowJo
  10 compatibility.
- **Own rule** when FlowJo has no such feature. This app chooses, and says
  so.
- **Stricter than FlowJo** when FlowJo's behavior loses work or hides a
  problem, and a safer rule changes no FlowJo-compatible result.

## 3. Step 1: severe defects (fixed)

| UAT | Sev | Defect | FlowJo 10.6.2 | Decision | Why | Test |
|---|---|---|---|---|---|---|
| a4-01 | S1 | Cell cycle fit with 16384 bins never finished and blocked the app until reload | Histogram has `min(channel range, 1024)` channels; the user cannot set it (6.1) | Match: same rule; bins input removed | FlowJo compatibility, and it bounds run time (measured 1.7 s at 1024, 23 s at 4096 channels on D1 FSC-A) | `tests/cellcycle.test.ts` "cell cycle histogram resolution" |
| a2-01 | S2 | Dragging an imported quadrant's centre moved one of the four; sum differed from the parent | A quad is a rectangle with one open bound per axis; the centre drag moves all four (6.2) | Match: import such rectangles as one quadrant | The gate model must be FlowJo's. Membership is the same `[lo, hi)` test, so FlowJo counts do not change | `tests/wsp-quadrant.test.ts`; browser check: 165 + 463 + 2,128 + 114,109 = 116,865 after a drag |
| a3-02 | S2 | Adding an AF row made a square spectral matrix, applied as spillover | Explicit `spectral` flag; never the shape (6.3) | Match the flag: `SpilloverMatrix.kind` | A shape rule fails for any square spectral matrix. Unset `kind` keeps the old shape rule, so `$SPILLOVER`, .wsp and Gating-ML results are unchanged | `tests/autofluorescence.test.ts` "square spectral matrix" |
| a3-01 | S2 | `den_comp.csv` (header starts with `# `) could not be applied | No CSV matrix import (6.4) | Own rule: strip a leading `#` from the header; skip other `#` lines | FlowJo gives no rule to match; FlowKit's format is common. Channel matching stays exact on `$PnN`, as in FlowJo | `tests/compensation_stats.test.ts` "#"-prefixed header, den_comp.csv |
| a5-01 | S2 | One unrepresentable gate aborted the Gating-ML export (any FlowJo workspace with a Time gate gave no file) | No Gating-ML 2.0 export (6.5) | Own rule: skip and warn per population; write Time gates in raw units | Same policy as our .wsp export. Raw units for a linear gain are exact | `tests/gatingml.test.ts` "Gating-ML export skips what it cannot write" |
| a3-03 | S2 | Deleting a derived parameter used by gates or statistics broke them with no warning | Generic confirmation; no dependency check; no cascade (6.6) | Stricter: list the users and ask; no cascade | Prevents silent breakage. No cascade, as in FlowJo, so nothing is lost; Undo restores | `tests/derived.test.ts` "derived parameter users" |

Validation after step 1: `npx tsc -p .` clean; `npm test` 215 passed, 2
skipped; `npm run e2e` all checks pass (cell cycle now 55.5 / 29.2 / 15.3
against truth 55 / 30 / 15). `src/core/wsp.ts` is an REA owner file, so the
REA ledger was regenerated (`docs/obligation-ledger.md`).

Known limit found during the fix: polygons and ellipses imported from .wsp
use FlowJo's gate grid, which Gating-ML cannot express. They export as exact
shapes, so their counts can differ after a Gating-ML round trip (specs 6.5).

## 4. Step 2: medium defects (planned; match FlowJo, specs 6.7)

| UAT | Defect | FlowJo behavior to match |
|---|---|---|
| a2-04 | Linear default T = 262144 for every channel | Range `0..$PnR` (1024 if missing) |
| a2-02 | Histogram overlays normalized under a "Count" label | Raw counts by default; "Normalized To Mode" option relabels the axis |
| a2-07, a2-08, a1-08 | Degenerate gates; duplicate sibling and group names | Discard shapes of 10 px or less; `-N` suffix; refuse duplicate rename |
| a1-04, a5-03 | Re-imported Gating-ML gates duplicate (React key errors) | Replace equivalent gates; ask "Replace?" otherwise |
| a5-04 | Quadrant names lost in a Gating-ML round trip | Keep the name in `custom_info` |
| a1-07, a5-02 | Same file added twice; mismatched relink accepted; no sample remove | Skip the same file; relink only on matching keywords; remove with confirmation |
| a4-02 | Percentile accepts any value; P0/P150 wrong | Integer 0..100; invalid input blocked |
| a4-03 | Proliferation generations 0/-1 give NaN | "Number of Peaks" 0..10, default 4; error, not NaN |
| a5-05 | Stats show old values while recomputing | Show "-"; export recalculates first |
| a4-05 | Platform errors only in the Log | Show the error in the platform window |
| a4-06 | Templates unnamed, lost on reload | Named, saved in the workspace |
| a2-09, a2-11 | NOT needs Ctrl-click; delete subtree without confirmation | NOT on the selection; confirm tree delete |
| a1-01, a2-16 | Live group-by message overpromises; opening a .wsp discards work | Membership only (fix the message); confirm before replacing the workspace |

## 5. Step 3: own UX choices (planned)

Escape closes every dialog (FlowJo binds Escape only in the rename dialog),
input checks on matrix files and cells (FlowJo accepts bad files silently),
stale log warnings, and the S4 layout items in the UAT report.
